### Issue: Fix vulnerability in serialize-javascript (Remote Code Execution)

The `serialize-javascript` package in our `package-lock.json` file is vulnerable to Remote Code Execution (RCE) due to misuse of `RegExp.flags` and `Date.prototype.toISOString()`.

**Recommended Steps:**
1. Upgrade to a safe version: 
   - Versions >= `2.1.1` (if compatible) 
   - Versions >= `3.1.0` (if there are no compatibility issues)
2. Run `npm audit` and `npm audit fix` to identify and automatically patch any issues.
3. If unresolved, update dependencies manually:
   - Modify `package.json` and enforce the new version
   - Remove `node_modules` and `package-lock.json`
   - Run `npm install`.

**Commands for Reference:**
- To detect affected version: `npm ls serialize-javascript`
- To verify resolution after fix: `npm audit`

**Priority:** High

This issue should be resolved to eliminate the risk of RCE within the dependency.
